# Doc Viewer (view-only PDF / DOCX / XLSX)

Build the APK with GitHub Actions:
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab -> **Build APK** -> wait for the green check.
3. Open the finished run, scroll to **Artifacts**, download **DocViewer-apk**, unzip it, install `app-debug.apk`.
(You may need to allow "Install unknown apps" for your browser/file manager.)
